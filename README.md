# Stack bytecode VM

Простая стековая виртуальная машина на C++17. Учебный проект: тесты, санитайзеры, отладка.

## Что внутри

- **Стек** (до 256 значений) и **локальный стек** (до 8 значений).
- Программа это массив `int`: опкоды и их операнды.
- Любая ошибка выполнения бросает `Vm::VmError` с понятным сообщением.

## Набор команд

| Команда | Что делает |
|---|---|
| `PUSH n` | кладёт `n` на стек |
| `ADD`, `SUB`, `MUL`, `DIV` | арифметика над двумя верхними значениями (`a op b`, где `b` верх стека) |
| `DUP`, `SWAP`, `POP` | дублировать верх, поменять два верхних, снять верх |
| `STORE n` | кладёт число `n` в локальный стек |
| `LOAD` | снимает верх локального стека и кладёт его на основной |
| `JMP addr` | безусловный переход на `addr` |
| `JZ addr` | снимает значение со стека, при `0` переходит на `addr` |
| `HALT` | завершает программу, возвращает верх стека |

Ошибки: пустой стек, переполнение стека, деление на ноль, переполнение `int`, неверный адрес перехода, обрезанный операнд, неизвестная команда, программа без `HALT`, превышение лимита шагов (по умолчанию 1 000 000).

## Пример

```cpp
#include "vm.hpp"

Vm vm({Vm::PUSH, 5, Vm::PUSH, 7, Vm::ADD, Vm::HALT});
int result = vm.run();   // 12
```

## Технологии

- **C++17**
- **CMake** (3.20+) и сборка через **Ninja**
- **Google Test / Google Mock** (v1.15.2), подтягивается автоматически через `FetchContent`
- **Boost** (1.69+), библиотека `Boost.SafeNumerics` для проверки переполнения `int`
- **AddressSanitizer и UndefinedBehaviorSanitizer** включены в сборку

## Установка зависимостей (macOS)

```bash
brew install cmake ninja boost
```

## Сборка и запуск тестов

```bash
cmake -S . -B build -G Ninja
cmake --build build
ctest --test-dir build --output-on-failure
```
